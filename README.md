# consoul

consoul is a named invitation for a supporting research story: persistent worlds and physical hardware, and attributable computational environments.

This repository is currently a placeholder. It is not a published specification or implementation. It is not a substitute for the governance mechanism examined through the [ARC Examiner Kit](https://github.com/arc-open-governance/arc-examiner-kit) and the [Consequential Reachability Benchmark](https://github.com/arc-open-governance/Consequential-reachability).

This publication does not claim that a First Room exists, and it does not claim a native PlayStation 4 boot or public N1 acceptance.

Research participation does not grant authority over production systems or institutional governance.

Open scientific challenge is welcome. No one has to accept a thesis in order to participate.
